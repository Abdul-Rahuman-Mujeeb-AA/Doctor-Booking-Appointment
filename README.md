# MediCare - Doctor Appointment Booking Website

A modern, responsive, frontend-only Doctor Appointment Booking Website built with React, Vite, and Tailwind CSS.

## Features

- 🏥 Browse 20+ verified doctors across 20 specialties
- 🔍 Search and filter doctors by name, specialization, fee, rating, and experience
- 📅 Book appointments with date and time slot selection
- 💻 Online and in-person consultation options
- 👤 User registration and login (localStorage-based)
- 📊 Dashboard with appointment statistics
- 📋 Manage appointments (view, cancel, details)
- 👤 Editable user profile
- 📱 Fully responsive design
- 🔔 Toast notifications
- ⚡ Fast loading with loading states
- 🚫 Duplicate booking prevention

## Tech Stack

- React 18
- Vite
- Tailwind CSS 4
- React Router DOM
- Lucide React (icons)
- Formik + Yup (form validation)
- React Hot Toast (notifications)

```bash
